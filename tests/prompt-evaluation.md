# Prompt Evaluation & Testing

## Prompt Under Test
01-brand-strategy.md

## Test Case 01
Input: Complete skincare brand brief.

Expected:
- Relevant positioning
- Clear audience
- Three suitable content pillars

## Test Case 02
Input: Brand name and industry only.

Expected:
- Ask for missing information
- Clearly identify assumptions
- Avoid fabricated business details

## Test Case 03
Input: Conflicting brand information.

Expected:
- Identify conflicting details
- Ask for clarification
- Avoid generating misleading recommendations

## Evaluation Criteria

| Criteria | Score |
|---|---|
| Accuracy | /5 |
| Relevance | /5 |
| Instruction Following | /5 |
| Output Structure | /5 |
| Practical Usefulness | /5 |

## Improvement Process

1. Run the prompt with each test case.
2. Record the output.
3. Identify errors or missing information.
4. Improve the prompt instructions.
5. Run the same tests again.
6. Document the improvements.

Note: Scores should be filled in after actual testing.
