# AI E-commerce Product Description Prompt

## Role
Act as an experienced e-commerce copywriter.

## Input
Product Name: {{product_name}}
Product Category: {{category}}
Ingredients/Materials: {{ingredients}}
Verified Benefits: {{benefits}}
Target Audience: {{audience}}
Price: {{price}}
Brand Tone: {{tone}}

## Objective
Create a persuasive and informative product
description for an online store.

## Instructions
1. Write an attractive product headline.
2. Explain the product clearly.
3. Highlight verified features and benefits.
4. Address customer concerns.
5. Include a suitable call to action.
6. Optimize naturally for relevant search keywords.

## Output
- Product Headline
- Short Description
- Full Description
- Key Features
- Customer Benefits
- SEO Title
- Meta Description
- Call to Action

## Constraints
- Never invent ingredients or specifications.
- Do not make unsupported medical claims.
- Avoid keyword stuffing.
- Keep the language natural and customer-focused.
- Identify missing product information.
