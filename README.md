3. Replace the variables with your business information.
4. Paste the prompt into your chosen AI model.
5. Review the generated output.
6. Test and refine the result based on your requirements.

## Prompt Engineering Methodology

Every professional prompt should define:

1. Role — What expertise should the AI adopt?
2. Context — What business information does it need?
3. Objective — What problem should it solve?
4. Input — What information will the user provide?
5. Constraints — What rules must it follow?
6. Output Format — How should the result be structured?
7. Quality Criteria — What makes the output successful?

## Quality & Testing
